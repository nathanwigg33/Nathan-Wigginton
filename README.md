# Chapter & Verse

A daily Bible verse game (KJV). Every day you get five verses, from famous to obscure. Find each one on the bookshelf (testament, book, chapter, verse) and score up to 1000.

It's a plain static site: `index.html`, `data.js` (verse pools and chapter/verse counts) and a few icons. It needs no build step. Host the repo root on Cloudflare Pages, Vercel, Netlify or GitHub Pages.
