How to play

Every day you get five verses. Verses 1–3 are easy, verse 4 is medium, and verse 5 is hard.

Find each verse on the shelf. Pick the book, then the chapter, then the verse. Each verse is worth up to 200 points, so a perfect day is 1000.

Right testament20
Right book (partial credit if you're a few books away on the shelf)80
Right chapter (partial if close)60
Right verse (partial if close)40

Stuck? Tap 💡 Book clue (−20) for a clue about the book, then 💡 Context clue (−40) for what's happening in that part of the story.

You only earn chapter points if you found the right book, and verse points only if you found the right chapter. Everyone gets the same five verses each day, and a new set comes out at midnight.
